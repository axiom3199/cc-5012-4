# 跟唱校正示例与运行说明

本文档说明如何在界面里启动逐字跟唱与音节时间校正，并覆盖对唱 / 轮唱双声部的全部操作路径。
逐字跟唱不是独立脚本：界面控件全部由 `src/correction.js` 的逐字内核驱动，内核失败会把原因
回传到页面状态栏，而不是静默丢弃。

## 1. 启动方式

```bash
npm run serve        # 等价于 python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

模块用的是 ES Module，必须经 HTTP 访问，不要用 `file://` 直接双击打开。

自动化测试（无需浏览器）：

```bash
npm test             # node tests/test.mjs && node tests/integration.mjs
```

## 2. 界面怎样启动逐字跟唱

1. 打开页面后，点击右上角 **“对唱轮唱样例”**。浏览器会合成一段 6.8 秒立体声音频
   （声部 A 在左声道、声部 B 在右声道），并自动载入两个声部的歌词与时间。
2. 在卡片 **“2. 词句时间与声部归属”** 勾选 **“逐字跟唱预览”**，画布立即进入逐字高亮：
   高亮按字素簇推进，连字 / ZWJ 表情等原子塑形段不会被切开。
3. 在词表中**点选**一个词（例如声部 A 的 `star`，它的逐字时间被故意做偏，第一字占了 60%
   时长），再到卡片 **“3. 逐字跟唱校正”** 点击 **“对当前选中词开始校正”**。
4. 校正条出现后：
   - **拖动音节之间的橙色竖线**：联合移动左右两个音节的相邻边界；画布高亮区间实时同步。
   - 若拖动会造成区间倒置或越界，边界不会移动，卡片底部红色状态栏给出具体原因
     （例如“边界不能早于或等于左侧音节的起点”），这就是内核失败回传逐字跟唱控件。
   - **“拖到播放头：整词起点 / 终点”**：先把播放头停到听到的发音位置，再点按钮，整词
     外沿移动且所有音节按比例伸缩。
5. 点击 **“▶ 播放”**（或按空格），眼睛盯画布上 `star` 的逐字高亮、耳朵听左声道合成音，
   核验高亮字形范围与声音是否对应；不准就暂停后继续拖边界。拖动进度条跳转后，两个声部的
   高亮都会按新播放时刻立即重算。

## 3. 对唱 / 轮唱的四个必测场景（样例已内置）

| 场景 | 样例位置 | 预期表现 |
| --- | --- | --- |
| 一方延长音跨过另一方两句 | A 声部 `hold` 2.00–4.60s，B 声部在此期间唱完 `one two` 两句 | A 的 `hold` 全程保持高亮，B 正常换词，两条泳道各自独立 |
| 同词同刻出现 | 两声部 `echo` 均为 0.60–1.00s | 0.8s 时两个 `echo` 实例同时高亮，颜色分别为 A 黄、B 蓝，互不覆盖 |
| 声部临时隐藏 | 卡片 4 中把 B 切到“临时隐藏”，或 A 设为“参考声部（不高亮）” | 只改变绘制：隐藏不绘制、参考声部灰显且无高亮；原始时间不变，泳道位置不交换 |
| 播放跳转 | 拖动底部进度条到任意时刻 | 两个声部按各自时间线立即解析活动词与活动字素，见测试“seeking restores…” |

短暂停顿（B 声部 3.10–3.40s 静默）期间泳道上下顺序保持不变——泳道按声部索引固定分配，
不随播放状态重排。

## 4. 拖选歌词并切换声部

1. 在词表按住鼠标（或触摸）**跨行拖动**，选中若干词实例。
2. 点击 **“所选 → 声部 A / 声部 B”**。词实例的 id 与已确认时间原样保留，只有归属声部
   改变，画布高亮字形与歌曲播放随即按新归属更新。
3. 切换后在卡片 1 的声部页签间切换，可看到歌词文本已同步；再次“应用歌词”不会丢时间。

## 5. 冲突报告与导出

- 卡片 4 的冲突框区分两类信息：
  - **[冲突] 同声部时间重叠**：一个声部不能同时唱两个词，需要修正；
  - **[冲突] 布局冲突**：某声部内容超出固定泳道高度，需缩小字号或减少每行字数；
  - **[正常] 跨声部重叠**：对唱 / 轮唱的预期情况，仅作信息展示。
- 点击 **“导出测试视频”** 时先跑 `validateExport`：存在同声部重叠或布局冲突会拦截并弹出
  实际冲突内容。
- 导出开始时冻结快照：声部选择、每个声部的视图模式、布局版本号写入清单 JSON
  （随视频一起下载）。导出过程中再切换声部或改字号，不影响正在生成的视频；若一次导出
  尚未结束又触发了新的导出（代次更新），晚到的旧结果会被丢弃，提示“已过期”，不会覆盖
  当前预览。

## 6. 初版独唱工程

保存的工程为 version 2。打开旧版 version 1 工程时自动迁移为单声部工程：所有词归入声部 A、
声部 B 留空，词 id 与时间记录不变，并弹窗提示迁移结果。这不是两段预录字幕视频的叠放——
所有渲染都来自同一份分声部词时间线与同一个 `renderAt(t)`。
